## App Store Connect Workflow

### 1. Create App Record
1. Log into App Store Connect
2. Click "My Apps" → "+" → "New App"
3. Select iOS platform
4. Enter app name: "BalanceTrack AI"
5. Select primary language: English
6. Enter Bundle ID: com.balancetrack.ai
7. Enter SKU: balancetrack-ai-001

### 2. Upload Build
```bash
# Using Xcode
1. Archive the app (Product → Archive)
2. Click "Distribute App"
3. Select "App Store Connect"
4. Upload
5. Wait for processing (10-30 minutes)
```

### 3. Complete App Information
1. Add app description
2. Upload screenshots
3. Add keywords
4. Set pricing
5. Configure App Privacy
6. Add reviewer notes

### 4. Submit for Review
1. Click "Submit for Review"
2. Answer export compliance questions
3. Answer advertising identifier questions
4. Confirm submission

### 5. Review Process
- **Average time**: 24-48 hours
- **Status updates**: Via email and App Store Connect
- **Possible outcomes**: Approved, Rejected (with reasons), Metadata Rejected
